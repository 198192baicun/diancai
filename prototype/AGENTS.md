# 交互原型

遵守根目录约束。原型使用共享本机状态，不连接正式服务，不伪装真实微信或 Linux 验收。

源文件为 `src/domain.js`、`src/app.js`、`src/styles.css`；`index.html` 由 `../tools/build_prototype.py` 生成。不要直接编辑生成文件而不更新来源，也不要只改截图。保持自包含、无外部 CDN、无第三方跟踪请求。

动作按 data-action 与实体 ID 绑定，重复菜品/不同日期/不同操作者必须指向正确事项。页面共同读取状态，不以互不关联的静态卡片模拟完成流程。错误、取消、冲突和未知结果与成功路径同等维护。

文件示意、网络与并发模拟必须明确标识。原型存储只能表达本机演示；不得声称支持真机上传或多设备联机。当前步骤附图的产品规则在 docs 中，原型文本步骤不能冒充文件管线实现。

修改后从根目录执行领域检查、构建脚本和浏览器检查。检查至少覆盖 320/375/430px，核对实际截图中的标题、正文、按钮与输入，不只看 HTML 能否解析。截图等待临时 Toast 消失，不能让瞬时遮挡成为页面基准图。测试用存储替身与运行时管理策略边界必须保留在记录中。

初始化页和设置页只读展示北京时间。演示日期仍固定为 2026-09-10。备份计划只作文字说明，不模拟已安装计划任务或虚构上次成功时间。源码变动后生成 HTML，并重跑浏览器检查与截图。

浏览器截图产生后运行 `python3 tools/build_previews.py` 生成页面预览索引和总览图，不保留来自不同交互源码的展示图。该脚本只使用本机字体，不随包分发字体文件。
