# 家庭点菜 · 交互原型

用现代浏览器打开本目录 `index.html`。它是一份自包含 HTML，无需构建、安装依赖或访问外部资源。独立 HTML 与完整目录具有相同页面功能。

初始选择“妻子”进入演示家庭；“我的”可以切换成员。演示日期固定为 2026-09-10，所有菜品封面均为示意插画。桌面左侧提供页面与场景入口，窄屏使用顶部“演示场景”；这些入口不会成为正式微信产品功能。

## 建议体验顺序

先到“点菜”将同一道菜加入两次，在已选页分别写备注并提交；到首页检查两个独立事项。选择另一成员认领其中一条，再进入事项选择完成或“不做了”；回到历史查看仍保留的记录。首页“往日未完成”保持原日期，可继续处理。

投票初始是并列票。作为发起人结束时选择获胜菜，回首页重新进入最近结果，再将获胜菜加入菜单；同轮不会加入第二次。评价可修改自己的星级和文字，不覆盖其他成员。

打开“下次提交结果未知”场景后提交，已选内容进入锁定状态；点击“确认提交结果”核对同一个意图。离线、认领冲突、版本冲突、加载和空菜单均有独立场景。某些场景会改变或清空本机演示数据，执行前会确认。

## 边界

页面不连接真实 API，也不是可编译微信工程。文件选择只作本机元信息/临时预览，不上传，不持久保存原文件字节；步骤当前演示文本。多个浏览器不会同步数据。

演示使用浏览器本地存储；浏览器禁止存储时可能无法保留数据，待确认凭据不能保存时不会发送模拟提交。交付检查使用 HTML 渲染与测试存储替身，未代替用户浏览器原生存储或微信真机验收。

`screenshots/` 是同一原型的页面截图；`preview.html` 提供页面概览。完整项目中的 `docs/03_交互设计.md` 与 `docs/05_开发与验收.md` 说明产品规则和实际验证范围。

家庭初始化与设置只读展示北京时间（Asia/Shanghai）。设置中的每日 04:00 备份说明是产品计划，不代表正在连接真实服务或已经安装计划任务。
