# 接口契约

遵守根目录约束。`http-api.md` 是当前 HTTP 设计契约，不是实现源码；`server/` 与原生客户端共同依赖它，不能让实现反向覆盖契约语义，也不能以原型短字段名取代正式 DTO。

每个写接口必须明确参数、操作者、实例/代次、状态前置条件、原子性和稳定错误码。说明首次执行与重放、revision 冲突、日期变化、资源停用、恢复代次及迟到响应行为。

回执可读不等于可新写；source_vote 唯一不等于可以绕过候选与日期检查。不要新增菜品物理删除、网页数据库恢复或任意路径文件接口。

新增/改变字段同时核对数据库表示、产品规则、原生客户端和测试。开放式描述必须落为明确约束；不能写“按需要返回”而让两个 Agent 各自推测。未来生成 OpenAPI 时必须覆盖现有语义并通过实际校验，不交付空占位文件。

setup 输入只含 familyName 与 members，不接收 timezone；服务固定写入 Asia/Shanghai。system 的 timezone 即使未初始化也返回该固定值，meta.today 按北京时间生成。
