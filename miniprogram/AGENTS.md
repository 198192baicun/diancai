# 微信原生客户端

遵守根目录约束。当前目录包含原生微信小程序工程。维护前读交互设计、HTTP 契约及实际接入验收条件；界面与交互以原生 WXML/SCSS/TypeScript 实现，不把浏览器 HTML 包装成正式工程。

原生页面使用统一请求适配、明确的实体 ID、按服务/实例/代次/成员隔离的草稿与待确认凭据。写请求发送前先持久化提交意图；存储失败则不发送。响应按发送时上下文归属，切换成员不会改写另一人的内容。

缓存和按钮不是权限边界；业务以服务结果为准。离线不排队自动提交。结果未知必须冻结同一 Key 和载荷；旧代次只提示核对，不自动补送。

区分菜品与菜单事项路由。状态、日期、统计、获胜菜加入状态使用服务 DTO，不在每页另造静态数据。下架不隐藏历史；取消和取消认领的含义不可混淆。

原文件接收能力与本机显示能力分开。所有支持承诺必须经过真实微信、目标手机和实际发布方式验证；不携带原型 `__demo`、模拟数据或场景入口发布。覆盖页面重开、前后台切换、成员切换、弱网、存储不足、上传取消与窄屏触控。没有真机证据时不得标记接入已通过。

家庭初始化和设置只读展示北京时间，不提供时区选择。日期取服务响应，不取手机默认日期；04:00 是维护时间而不是菜单日界线。服务不可达不能仅凭时间猜测正在备份。
