# 本地工具

遵守根目录约束。本目录只放项目确实会使用且可执行的工具，不为说明文字创建空脚本。

`build_prototype.py` 从固定本地来源生成自包含 HTML，无网络访问，不改业务数据。输出应可复现，出现缺失输入直接失败；不把执行环境秘密嵌入产物。

批量处理必须限定项目根或临时目录。生产发布、备份与恢复工具属于 deploy 的安全范围，不能作为普通构建附带执行。新增工具说明输入、输出、依赖、失败返回码和是否写文件。

构建后运行相关检查；路径、日志和错误信息保持清楚，不隐藏失败。工具源码可以进入设计包，缓存、临时数据库、浏览器用户目录和依赖文件夹不进入交付。

构建和检查工具不安装定时任务，不自动停服。backup-policy.json 是实施契约；只有真实维护命令完成并经过 Linux 验收后才生成、安装调度单元。
