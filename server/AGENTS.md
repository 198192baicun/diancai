# 服务端

遵守根目录约束。负责真实 API、参数转换、业务事务、SQLite 连接和媒体管线，不负责原型演示状态。

实施前读 `../docs/01_产品规则.md`、`../docs/02_系统与数据设计.md`、`../contracts/http-api.md`。按 family/catalog/menu/vote/media 组织业务；可以按复杂度拆模块，不建立无实际用途的通用仓储或 DI 框架。

所有写入显式接收操作者、服务上下文与业务时钟。统一检查实例/数据代次；在事务内执行状态、权限、版本和依赖校验。每个连接设置外键、超时与同步策略。生产驱动实际链接 SQLite 不低于 3.51.3；记录运行查询版本，而不仅看 npm 包版本。

批次成功回执与菜单同事务；重放先读成功回执再判新请求日期。文件 I/O 不占用长写事务，只有完整落盘文件可被业务引用。HTTP 不暴露数据库备份/恢复或任意路径下载。

本目录包含初始 DDL、HTTP/SQLite 开发运行实现和服务集成检查。服务接口结论只以 `tests/server.test.cjs` 等真实接口证据为准，不能把 `prototype/src/domain.js` 的通过结果写成服务接口已通过。提交前运行根目录领域/SQL检查、服务集成检查和客户端静态/类型检查；生产发布仍需 linux/amd64、Node/SQLite 版本、镜像与目标环境证据。

服务端唯一目标为 linux/amd64。家庭业务时区固定 Asia/Shanghai；初始化不接受客户端时区，日期生成不依赖系统默认值；启动核对数据库时区，单个事务使用一致时钟。
