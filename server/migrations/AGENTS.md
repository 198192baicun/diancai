# 数据结构

本目录继承根目录与 server 约束。`001_initial.sql` 为首次建库结构；测试数据不得混入正式 migration。任何已发布且执行过的 migration 内容与散列不可改写，后续结构用新的有序脚本。

非空、唯一、复合外键、部分索引和状态形状都需验证。注意 CHECK 的 NULL 语义；评分是严格整数，日期是真实公历日。业务权限仍由服务实现，不宣称 SQL 单独完成身份校验。

保存历史和媒体引用，禁止级联删除业务历史。所有代次、回执和来源投票唯一约束必须与接口一致。备份导入还需业务不变量与版本校验，不只执行 integrity_check。

从项目根目录执行 `python3 tests/schema_test.py`。增加/调整结构时同步系统文档、接口 DTO 和临时数据库用例，包含两个连接的竞争条件。不得对生产库直接试验 DDL。

app_meta.timezone 只允许 Asia/Shanghai；初始 DDL 与产品、初始化契约和部署环境一致。用独立临时库测试 NULL、空串和其他时区被拒绝。
